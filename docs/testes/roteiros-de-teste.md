# Roteiros de Teste

Roteiros de teste manuais do Chiclete, no formato de tabela definido pelo "Template Roteiros de Teste". Complementam o [`plano-de-teste.md`](plano-de-teste.md) (níveis automatizados: unitário, integração e BDD) com casos de execução manual, passo a passo, para validação funcional.

| ID | Prioridade | Funcionalidade | Objetivo | Pré-condição | Dados de teste | Passos | Resultado esperado | Resultado obtido | Status | Evidência |
|----|------------|----------------|----------|---------------|-----------------|--------|---------------------|--------------------|--------|-----------|
| RT-01 | 🔴 Alta | Cadastro e login | Validar que um novo usuário consegue se cadastrar e autenticar com sucesso | Aplicação disponível; email ainda não cadastrado | Nome: "Maria Silva"; email: "maria.silva@teste.com"; senha: "senha123" | 1) Abrir a tela de cadastro<br>2) Preencher nome, email e senha<br>3) Submeter o formulário<br>4) Ir para a tela de login e informar as mesmas credenciais<br>5) Submeter o login | Cadastro retorna sucesso (201); login retorna token JWT válido; usuário é redirecionado para a tela de lembretes | | 🟡 Planejado | |
| RT-02 | 🔴 Alta | Criar e concluir lembrete | Validar a criação de um lembrete e sua marcação como concluído | Usuário autenticado | Título: "Estudar para prova"; data/hora: data futura; prioridade: "ALTA" | 1) Logar na aplicação<br>2) Criar novo lembrete com título, data/hora e prioridade informados<br>3) Localizar o lembrete na lista de pendentes<br>4) Marcar o lembrete como concluído | Lembrete aparece na lista "Pendentes" após criação; ao ser concluído, desaparece de "Pendentes" e passa a aparecer em "Concluídos" | | 🟡 Planejado | |
| RT-03 | 🟡 Média | Autenticação — login com credenciais inválidas | Validar que o login é rejeitado quando a senha informada está incorreta | Usuário já cadastrado com email "login-fail@teste.com" | Email: "login-fail@teste.com"; senha: "senhaErrada" | 1) Abrir a tela de login<br>2) Informar o email cadastrado e uma senha incorreta<br>3) Submeter o login | Login é rejeitado (HTTP 401); mensagem de erro é exibida na interface; nenhum token é gerado/armazenado | | 🟡 Planejado | |
| RT-04 | 🟡 Média | Criação de lembrete — título obrigatório | Validar que não é possível criar um lembrete sem informar o título | Usuário autenticado | Título: vazio ("" ); data/hora e prioridade preenchidos normalmente | 1) Abrir o formulário de novo lembrete<br>2) Deixar o campo título em branco<br>3) Preencher os demais campos<br>4) Tentar salvar o lembrete | Envio é bloqueado pela validação do formulário ou a API retorna erro de validação (400); o lembrete não é criado | | 🟡 Planejado | |
